## 这是什么

本目录放的**不是** `prototype/` 里那个 Three.js 空间原型，而是 2026-09-30 定稿的
**Layer 1 平面导航 UI**（底部 5 Tab + 常驻迷你播放条 + 二级页 + 独立全屏播放页）。

它把此前 11 个各自独立展示的原型**合体成一个可跑的 App**：单文件、零依赖、零网络请求
（封面是 `linear-gradient` 程序化占位，图标是内联 SVG，无字体文件、无 JS 库）。

| 文件 | 用途 |
|---|---|
| `index.html` | **手机端直看版**：只保留手机框里的设计，铺满整屏（`100dvh` + 安全区适配）；桌面打开时居中成 390×844 便于对照 |
| `app.html` | 完整原型（含原型台：配色 chips、说明栏、手机外框），用于桌面评审 |

## 已实现的内容

| 项 | 说明 |
|---|---|
| 导航 | 底部 5 Tab：首页 · 歌单 · 统计 · 白噪音 · 设置；常驻迷你播放条 56dp（上一首 / 播放 / 下一首），白噪音状态为封面右上角角标 |
| 二级页 | 歌单详情 · 歌手详情 · 专辑详情 · 搜索 · 下载管理 · 均衡器 · 设置详情（自右滑入 / 右滑出，28% 视差） |
| 播放页 | 独立全屏，自底滑入；封面 ⇄ 歌词；四态歌词；**立体歌词**（整块板旋转 + 双采样测量 + 板宽按角度重算）与半高参数面板 |
| 配色 | 六套实测情绪配色（④ 白 / ⑤ 灰 / ⑤b 灰深 / ① 暗绿 / ①b 暗绿软 / ② 冷蓝），在「设置 → 外观」里点卡切换 |
| 转场 | 严格照 `16 §4`：Tab 200ms 交叉淡入淡出 · 进详情 300ms 右滑入 + 视差 · 返回 200ms · 播放页 300ms 底滑入 / 200ms 下滑出 · 弹层 300ms + 遮罩 260ms · 列表项 200ms + 40ms stagger |
| 文案 | 110 条 inmyfeelings 文案（6 分类 × 4 时段） |
